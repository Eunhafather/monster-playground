# 몬스터 친구 탐험대 v0.3

아이패드 Safari용 영어·숫자 놀이입니다.

## 영어 6유형
먹이 이름, 색깔, 행동, 상황에 맞는 인사, 큰 것·작은 것, 위·아래·안.
영어 안내와 선택한 인사 표현은 영어 뒤에 한국어 뜻을 읽습니다.

## 수학 9유형
드래그 더하기, 드래그 빼기, 개수 세기, 많고 적음 비교, 목표 개수 채우기, 빠진 숫자, 반복 규칙, 같은 모양, 크기 비교.

## 반복 줄이기
골고루 놀기는 한 번에 서로 다른 4유형을 섞으며, 덜 해본 유형을 우선합니다. 최근 문제와 똑같은 내용이 다시 나오는 것을 가능한 범위에서 피합니다. 문제 공간이 작은 유형은 반복될 수 있습니다.
보호자 메뉴에서 한 유형만 연습할 수도 있습니다. 쉬운 수준은 수량 3 이하, 기본은 5 이하를 유지합니다.

## 사용·개인정보
[놀이터 열기](https://eunhafather.github.io/monster-playground/)
Safari에서 열고 보호자 메뉴에서 소리를 확인하세요. 홈 화면에 추가할 수 있습니다.
스티커와 설정은 해당 브라우저에 저장하며, 기존 v0.2 기록을 유지합니다. 마이크, 로그인, 유료 AI API는 없습니다. 프로그램은 개인 기록을 서버로 전송하지 않습니다. OS 음성 서비스에는 해당 환경의 정책이 적용됩니다.
음성은 실제 성우 녹음이 아닌 기기 음성 읽기 기능입니다. 보호자 메뉴는 기기 잠금이 아닙니다.
캐릭터는 독자적인 몬스터이며 포켓몬 원본 이미지를 사용하지 않습니다.
