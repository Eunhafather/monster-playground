# 포켓몬 친구 연구소

v0.28: AB, ABC and AAB repeating-shape question choices are drawn exclusively from the shapes actually present in their patterns, for every learning stage. Two-shape patterns always offer both of their shapes; three-shape patterns offer all three, including the correct missing shape. Matching colors and single-row layouts preserved. Deliberately different-shape classification questions remain unchanged. Grading, navigation, saved records and all earlier changes retained; 3D remains on hold.
