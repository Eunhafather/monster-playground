# 몬스터 친구 탐험대 v0.11

아이패드 Safari에서 https://eunhafather.github.io/monster-playground/ 를 열어 바로 사용하세요. 로그인·유료 AI 연결은 없습니다. 공유 → 홈 화면에 추가로 앱처럼 실행할 수 있습니다.

## 학습 단계와 유형

보호자 설정에서 영어와 수학을 각각 **6세 / 7세 / 초등 1학년** 단계로 고릅니다. 각 단계의 영어 50개, 수학 50개 학습 목표 항목으로 총 300개 단계별 카탈로그 항목이 있습니다. 연령 간 목표는 연속적으로 공유하며, 같은 화면을 재사용하기도 합니다. 300개의 전혀 다른 화면 형식을 뜻하지 않습니다.

- 영어: 생활 단어, 색·모양·위치, 움직이는 행동 GIF, 분류, 감정·날씨 문장, 글자·소리, 단수·복수, 기초 문장 연결, 질문과 대답, 예의 있는 대화, 지시 순서, 단어 카드 문장 만들기.
- 수학: 세기, 수 비교·순서, 수직선, 끌어서 더하기·빼기, 계산식, 이야기 문제, 빈칸 식, 묶음·가르기, 반복·증가 규칙, 도형·위치, 길이·높이·무게·물의 양, 시계, 하루 순서, 그림표·분류.
- 6세: 영어 보기 2개 중심, 수학 계산 10 이하, 단순 세기 그림 수량 8 이하.
- 7세: 영어 보기 3개 중심, 수학 계산 20 이하, 수 비교·순서 30까지.
- 초등 1학년: 영어 수량 표현 20까지 및 더 긴 단어 카드 문장, 수학 계산 20 이하, 수 개념 100까지.

연령 표시는 권장 학습 단계이며 개인차가 큽니다. 일부 문법·시계·소리 활동은 보호자의 안내가 필요합니다. 영어는 초등 1학년 정규 교과가 아닌 조기 학습 활동입니다. 모든 교육과정을 대체하지 않습니다.

## 한 라운드

서로 다른 다섯 유형을 2문제씩, 총 10문제 풉니다. 보호자에서 첫 번째부터 다섯 번째까지 유형을 지정하거나 덜 해본 유형부터 자동 선택합니다. 자동·직접 선택을 섞을 수 있고, 중복 유형은 자동으로 다른 유형을 고릅니다. 유형 지도에서 골라 시작하면 선택한 유형 2문제 + 다른 네 자동 유형 8문제로 진행합니다. 보기를 눌러도 정답 여부는 즉시 표시하지 않습니다. 선택은 언제든 바꿀 수 있고, 다음 놀이를 누르면 답을 확인합니다. 맞으면 **잘했어요!** 팝업이 뜨고, 팝업의 다음 문제를 누르면 진행합니다. 틀리면 **다시 생각해보세요** 팝업이 뜨며, 다시 고르기를 눌러 같은 문제에서 재선택합니다. 10번째 문제의 놀이 마치기와 정답 팝업의 결과 보기를 확인한 뒤에만 보상이 한 번 지급됩니다. 팝업을 닫기 전 반복 제출은 막습니다.

## 랜덤과 중복 방지

모든 수학 유형의 연속 두 문제는 연산의 변화량·개수·비교 방향·규칙·빈칸 위치·시간 등 학습 조건이 다른 것을 우선 선택합니다. 물건이나 캐릭터만 바뀌고 계산 조건은 같은 문제를 별개 예시로 세는 일을 줄였습니다. 몇 개 더 모으기·덜어내기에서는 1~5개로 변화량을 바꾸며 연령별 계산 범위를 지킵니다. 계산식·모임 그림·짧은 이야기 표현도 섞습니다. 도형 이름·0·정각처럼 학습 개념이나 가능한 답이 제한된 유형의 모든 문제가 완전히 다른 학습 목표가 되는 것은 아닙니다.

각 단계·과목·유형마다 결정적인 문제 풀을 준비하고, 그 안에서 무작위 비복원 추출합니다. 유형당 최대 96개 예시를 순환합니다. 시계처럼 가능한 답이 제한된 유형은 더 적습니다. 단어·상황·그림·수·조건을 조합하며, 보기 순서만 바뀐 것은 새 문제로 세지 않습니다. 준비된 예시를 모두 만나기 전에는 같은 문제를 다시 내지 않고, 소진하면 새 순환 안내 후 다시 사용합니다. 순환 경계에서도 한 라운드 안에는 같은 문제가 중복되지 않습니다. 무한한 새 문제나 영구적인 무중복을 약속하지 않습니다.

사용한 예시와 연습 횟수는 이 브라우저의 로컬 저장소에 남습니다. 다른 기기·브라우저와 동기화하지 않습니다. 미완료 라운드도 이미 출제한 예시는 사용한 것으로 기록됩니다. 도감·기록 초기화는 중복 방지 기록도 초기화합니다. v0.10에서 문제은행은 b3로 갱신되어 새 예시 순환을 시작하지만, 기존 연습 횟수·도감·별·놀이 기록·음성 설정은 보존합니다.

## 소리·터치·오프라인

영어 다음 한국어 뜻을 읽습니다. 모든 영어 보기는 다음 놀이를 누르기 전까지 눌러 표현을 들을 수 있습니다. have·has, a·an처럼 뜻이 같거나 글자 자체를 고르는 활동은 선택 때 영어만 들려주며 중복 한국어 설명을 표시하지 않습니다. on·under, 일반 단어처럼 뜻의 구별이 필요한 보기는 영어와 한국어 뜻을 함께 들려줍니다. 보기 탐색은 다시 시도 횟수를 늘리지 않고, 틀린 답을 제출한 횟수만 기록합니다. 이미지 아래의 이쪽이에요 같은 일반 문구는 없고, 글자·숫자 보기는 본문 한 번만 표시합니다. 동작 그림은 세 친구의 실제 GIF이며, 동작 줄이기 설정에서는 정지 그림을 사용합니다.

한국어는 기기의 음성 합성으로, 자연스러운 성우 녹음이 아닙니다. 보호자에서 한국어 목소리를 골라 확인하세요. 유료 음성 개선은 이번 버전에 포함하지 않습니다. 처음 시작 및 소리 확인 버튼을 눌러 음성을 활성화하세요. 숫자 드래그를 사용하기 어려우면 보호자 도움 영역의 한 개 이동 버튼도 있습니다.

HTTPS에서 한 번 정상 접속하면 핵심 파일을 캐시해 오프라인 재실행을 지원합니다. 기기 음성의 설치·네트워크 조건에 따라 오프라인 음성이 나오지 않을 수 있습니다. 캐시·사이트 데이터를 지우면 기록과 오프라인 파일이 사라집니다.

업데이트가 보이지 않으면 Safari에서 페이지를 새로고침하고 하단 **v0.11**을 확인하세요. 기존 스티커·기록·목소리 설정은 보존하며, 이전 유형 선택은 대응되는 새 유형으로 옮깁니다.

## 한국어 조사 교정

화면과 음성 안내에서 받침에 따라 이/가, 은/는, 을/를, 과/와, 으로/로, 이에요/예요 등을 선택합니다. 으로/로는 ㄹ 받침 예외도 처리하고 숫자는 한국어 독음으로 판단합니다. 친구 이름은 대화에서 초롱이·반짝이·퐁퐁이로 자연스럽게 부릅니다. 예: 초롱이가 말해요, 반짝이는 어디에 있을까요, 연필을 찾아봐요, 사과가 있어요, 별은 몇 개일까요. 기존 첫 두 유형 선택은 보존하고 새 세 칸은 자동 선택으로 시작합니다. 기존 스티커·놀이 기록·문제 중복 방지 기록·목소리 설정도 보존합니다.

## 파이리 진화 라인

첨부된 다섯 PNG 원본을 바이트 변경 없이 사용합니다. 기존 세 친구와 기록은 남겨두고 선택 가능한 파이리 진화 라인을 추가했습니다. 파이리와 영어 또는 수학 라운드 10문제를 마치면 별 1개가 쌓입니다. 이 별은 파이리 진화 라인에만 쌓이며 기존 친구 스티커를 임의로 바꾸거나 합치지 않습니다.

| 별 | 모습 |
| --- | --- |
| 0~14 | 파이리 |
| 15~29 | 리자드 |
| 30~44 | 리자몽 |
| 45~59 | 메가리자몽 |
| 60 이상 | 거다이맥스리자몽 |

선택 화면·도감·동행 표시·완료 화면에 현재 모습이 반영됩니다. 진화 경계 라운드의 완료 화면에는 이전/새 모습을 함께 보여줍니다. 중간 종료나 보기 선택만으로 별은 주지 않습니다. 초기화는 별도 함께 지웁니다. 첨부가 정지 PNG이므로 새로운 포켓몬 행동 GIF를 임의로 만들지 않았고, 행동 학습 GIF에는 기존 학습 친구들이 등장합니다.

이는 앱에서 정한 학습 보상 성장 단계이며 공식 포켓몬 진화 규칙과는 다릅니다. 포켓몬 이미지·명칭 관련 권리는 각 권리자에게 있으며, 이 앱은 비공식 개인 학습용입니다. 공개 서비스·상업적 배포에서는 별도의 사용권을 확인하세요.

## v0.10 규칙과 보기 정리

수학 AB·ABC·AAB 반복 규칙은 실제 모양 6~8개와 그 사이의 빈칸 1개(전체 7~9칸)를 제시합니다. 마지막을 잇는 대신 빈칸 앞뒤의 규칙을 찾아 고릅니다. 작은 수·큰 수 순서 카드, 영어 알파벳·단어 카드, 시계 등의 글자/숫자는 보기마다 한 번만 표시합니다. 이쪽이에요 같은 일반 라벨은 없습니다. 필요한 그림의 단어 표시는 설정과 읽기 활동에 따르며, 영어 표현 듣기는 접근성 이름이 있는 소리 버튼으로 유지합니다.

## v0.11 오답 해설

영어·수학 각각 50개 학습 목표, 6세·7세·초등 1학년의 모든 300개 유형에서 틀린 답을 제출하면 고른 답, 정답, 해당 문제의 숫자·조건에 맞는 짧은 이유를 팝업으로 보여줍니다. 예: He 뒤에는 has, 시계의 긴바늘이 6이면 반, 모양의 반복 묶음, 두 수의 비교 관계, 실제 수량의 덧셈·뺄셈. 해설 듣기 버튼으로 다시 들을 수도 있습니다. 정답을 자동 선택하거나 점수를 주지 않고, 다시 고르기를 눌러 같은 문제에서 재선택합니다. 보기를 탐색할 때는 정답 여부를 드러내지 않습니다.

have·has는 가지고 있다는 공통 뜻을 선택할 때마다 반복하지 않습니다. 문법 차이는 오답 제출 후 해설에서 알려줍니다. 정답을 고른 뒤에도 제출하기 전까지 다른 표현을 탐색할 수 있습니다.

문제은행 b3는 그대로 유지하므로 v0.10의 사용 예시·연습 횟수·별·도감·기록·음성 설정을 보존합니다. 유료 음성은 추가하지 않았으며 한국어는 기존 기기 음성을 사용합니다.
