# 몬스터 친구 탐험대 v0.15

아이패드 Safari에서 https://eunhafather.github.io/monster-playground/ 를 열어 사용하세요. 로그인이나 유료 AI 연결은 없습니다. 공유 → 홈 화면에 추가로 앱처럼 실행할 수 있습니다. 하단 버전이 v0.15인지 확인하세요.

## 선택 가능한 세 친구

홈과 도감에는 파이리·이상해씨·꼬부기 세 계열만 나옵니다. 홈의 선택 버튼은 기본 모습을 보여주고, 큰 그림과 놀이 동행·완료 화면에는 선택한 계열의 현재 진화 모습이 표시됩니다. 도감의 세 버튼으로 계열을 살펴보고 이 친구와 놀기를 눌러 선택합니다. 초롱·반짝·퐁퐁은 선택 화면과 도감에서 제거했으며, 문제 속 그림과 이름도 세 포켓몬으로 교체했습니다.

| 별 | 파이리 계열 | 이상해씨 계열 | 꼬부기 계열 |
| --- | --- | --- | --- |
| 기본 | 파이리 | 이상해씨 | 꼬부기 |
| 15 | 리자드 | 이상해풀 | 어니부기 |
| 30 | 리자몽 | 이상해꽃 | 거북왕 |
| 45 | 메가리자몽 | 메가이상해꽃 | 메가거북왕 |
| 60 | 거다이맥스리자몽 | 거다이맥스이상해꽃 | 거다이맥스거북왕 |

선택한 친구와 10문제 라운드를 완료하면 해당 계열에 별 1개를 받습니다. 세 계열의 별은 독립적으로 모으며, 별은 소모되지 않습니다. 10번째 답의 정답 팝업에서 결과 보기까지 확인한 뒤 한 번만 보상합니다. 중간 종료나 보기 탐색만으로 별을 받지 않습니다. 이 단계는 앱에서 정한 학습 보상 방식이지 공식 포켓몬 진화 규칙은 아닙니다.

첨부된 15개 진화 PNG는 원본 바이트 그대로 사용합니다. 학습 장면에는 기본 세 모습과 이름을 사용합니다. 행동 문제에는 이 그림으로 만든 이동·위아래 점프·숨쉬기와 Z 표식의 간단한 GIF를 사용합니다. 원본과 다른 정식 포켓몬 애니메이션 영상이나 새 팔다리 자세를 제작한 것은 아닙니다. 기기 동작 줄이기 설정에서는 정지 그림으로 표시합니다.

## 학습 구성

영어·수학은 각각 6세·7세·초등 1학년 권장 단계의 50개 학습 목표가 있습니다. 총 300개 단계별 항목이며, 전혀 다른 화면 300개를 의미하지는 않습니다. 보호자에서 과목별 단계와 다섯 유형을 지정하거나 자동으로 덜 해본 유형을 고릅니다. 한 라운드는 서로 다른 5유형 × 2문제, 모두 10문제입니다.

- 6세: 영어 보기 2개 중심, 수학 계산 10 이하, 단순 세기 수량 8 이하.
- 7세: 영어 보기 3개 중심, 수학 계산 20 이하, 수 비교·순서 30까지.
- 초등 1학년: 영어의 수량 표현과 문장 카드 확장, 수학 계산 20 이하, 수 개념 100까지.

한 유형의 두 문제는 수량·조건·빈칸·비교 방향 등이 다른 문제를 우선 고릅니다. 유형당 최대 96개 준비된 예시를 비복원으로 추출하며, 가능한 예시가 적은 유형은 풀이 더 작습니다. 모두 소진하면 새 순환을 시작합니다. 무한한 새 문제나 영구적인 무중복은 약속하지 않습니다. 반복 모양은 실제 모양 6~8개와 중간 빈칸으로 제시합니다.

연령은 권장 단계이며 개인차가 있습니다. 영어는 초등 1학년 정규 교과가 아닌 조기 학습 활동입니다. 모든 교과 과정을 대체하지 않습니다.

## 선택·해설·음성

보기를 눌러도 즉시 정답으로 표시하지 않습니다. 다음 놀이를 눌러 채점합니다. 정답이면 잘했어요 팝업을 확인하고 다음 문제로 이동하며, 오답이면 고른 답·정답·짧은 이유를 보여주고 같은 문제에서 다시 선택합니다. 해설 듣기로 이유를 다시 들을 수 있습니다.

영어 보기 탐색은 영어와 자연스러운 한국어 뜻을 들려줍니다. have·has처럼 공통 뜻을 반복할 필요가 없는 보기는 영어만 들려줍니다. It is under/on/in the box.는 그것은 상자 아래/위/안에 있어요.로 해석하고, 문장을 나눠서 알아봐요 패널로 해당 문맥의 It·is·위치 표현을 우리말 순서로 연결합니다. 숫자·단어 보기의 중복 문구와 이쪽이에요 같은 일반 라벨은 없습니다.

한국어는 기존 기기의 음성 합성으로 성우 녹음이 아닙니다. 유료 음성 개선은 포함하지 않았습니다. 처음 보호자에서 소리를 확인하세요. 목소리 종류와 오프라인 음성 지원은 기기에 따라 다릅니다.

## 기록과 업데이트

파이리의 기존 별, 놀이 기록, 단계·목소리 설정, b3 문제은행 사용 예시는 보존합니다. 새 두 계열은 별 0개에서 시작합니다. 삭제한 기존 친구의 스티커를 새 포켓몬 별로 임의 변환하거나 합치지 않습니다. 이전 선택이 초롱이면 이상해씨, 반짝이면 파이리, 퐁퐁이면 꼬부기로 선택을 연결하며, 이전 놀이 기록과 숨겨진 기존 스티커 값은 내부 기록으로 유지합니다. 도감·기록 초기화는 모든 별과 학습 기록도 지우므로 주의하세요.

저장은 이 브라우저의 로컬 저장소에만 이루어집니다. 다른 기기와 동기화하지 않습니다. Safari 사이트 데이터를 지우면 기록도 사라집니다. HTTPS에서 한 번 접속하면 핵심 파일을 캐시해 오프라인 재실행을 지원합니다. 새 버전이 보이지 않으면 새로고침하고, 기록 보존을 위해 사이트 데이터 삭제는 피하세요.

포켓몬 이미지와 명칭의 권리는 각 권리자에게 있습니다. 이 앱은 비공식 개인 학습용이며, 공개 서비스·상업적 배포에서는 별도의 사용권을 확인하세요.

## v0.14 보기 표시 원칙 교정

영어 그림 보기에는 on·in·under, walking·jumping·sleeping, 색깔·물건 이름 등 실제 선택하는 영어 단어나 표현을 항상 한 번 표시합니다. 단어를 숨기는 이전 showWords 설정은 더 이상 보기 라벨을 숨기지 않습니다. 보호자 설정에서도 이 원칙을 안내합니다.

알파벳·단어·문장처럼 보기 자체가 텍스트인 경우에는 같은 내용을 아래에 다시 적지 않습니다. 숫자 보기도 값은 한 번만 표시합니다. 소유 관계 그림은 별도의 이름만 되풀이하지 않고 실제 선택하는 소유 표현 전체를 한 번 표시합니다. 이는 학습에 필요한 영어를 삭제하는 것이 아니라 동일 보기 안에서의 실제 텍스트 중복만 없애는 원칙입니다. 이쪽이에요 같은 불필요한 일반 문구는 넣지 않습니다.

보기 탐색, 완전한 문장 해석, 오답 해설, 제출 전 답 변경, 세 포켓몬 진화·별·기록은 유지합니다. 문제은행 b3와 출제 기록도 유지합니다.

## v0.15 자연스러운 부정 축약형과 입체 상자

부정 표현 do not → don’t, does not → doesn’t, cannot → can’t, is not → isn’t 등을 문제·보기·음성·해설·유형 설명에 일관되게 적용했습니다. 한국어 뜻과 정답 조건은 바뀌지 않습니다. 긍정 문장 It is 등 학습용 기본 구조를 임의로 모두 축약하지는 않습니다.

위치 그림의 납작한 네모 상자를 입체 종이상자 그림으로 교체했습니다. 윗면·앞면·옆면, 접힌 선, 포장 테이프, 배송 라벨, 명암과 그림자가 있습니다. on은 닫힌 상자 위, in은 열린 상자 안에서 앞벽이 몸 아래를 가리는 모습, under는 상자 아래로 구분합니다. 왼쪽·오른쪽·가까움·멀리·위·아래·사이·바깥 위치에도 같은 입체 상자 그림을 사용합니다. 보기의 영어 라벨은 한 번씩 유지합니다.

정답 제출 전 탐색, 오답 해설, 문장 나눠 해석, 세 계열의 별과 기록, 문제은행 b3 및 오프라인 실행을 유지합니다.
