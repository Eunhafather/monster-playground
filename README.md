# 몬스터 친구 탐험대

아이패드 Safari를 위한 영어·숫자 놀이 웹 앱입니다.

- 영어 안내 뒤 한국어 번역을 이어서 읽습니다.
- 기기에서 제공하는 한국어 목소리와 다정한 안내 느낌을 선택합니다.
- 열매를 바구니로 끌어 더하고, 몬스터 친구에게 끌어 주며 뺍니다.
- 스티커 도감과 간단한 놀이 기록을 해당 브라우저에만 저장합니다.

## 사용

웹사이트를 Safari로 열고 **보호자 → 한국어 소리 확인 / 영어→한국어 확인**으로 시작하세요.
Safari 공유 메뉴에서 홈 화면에 추가할 수 있습니다. 음성 품질과 저장 동작은 실제 기기에서 확인해 주세요.

## 개인정보와 한계

로그인, 유료 AI API, 마이크, 음성 녹음, 광고를 사용하지 않습니다.
프로그램 자체는 기록을 서버로 보내지 않습니다. 운영체제 음성 서비스에는 해당 환경의 정책이 적용됩니다.
음성은 실제 성우 녹음이 아니라 브라우저 음성 읽기 기능입니다.
보호자 메뉴는 기기 잠금이나 다른 앱 차단 기능이 아닙니다.
브라우저 데이터를 지우거나 접속 환경을 바꾸면 기록이 사라질 수 있습니다.

## 배포

정적 파일을 그대로 GitHub Pages로 제공합니다. 처음 온라인으로 열린 뒤 서비스 워커가 화면 파일을 캐시하도록 구성되어 있습니다.
오프라인 캐시 유지와 음성 재생은 기기에 따라 다를 수 있습니다.
캐릭터는 이 프로그램을 위해 만든 독자적인 몬스터이며, 포켓몬 원본 이미지를 사용하지 않습니다.
