# 몬스터 친구 탐험대

v0.6 · iPad Safari용 영어·수학 놀이

## 라운드
한 라운드 10문제: 첫 번째 유형 5문제, 두 번째 유형 5문제. 두 유형은 서로 다릅니다.
보호자에서 영어·수학 각각 두 유형을 선택하거나 자동 선택할 수 있습니다. 덜 해본 유형부터 고르며, 작은 문제 풀에서는 반복이 생길 수 있습니다.
10문제를 모두 마쳐야 스티커 한 장을 받습니다. 중간에 종료하면 이번 라운드 진행은 저장하지 않으며 이전 스티커는 유지됩니다.

## 영어 표현 탐색
그림을 누르면 그 보기의 영어 표현을 읽고 한국어 뜻을 이어 읽습니다. 예: on → 상자 위, under → 상자 아래, in → 상자 안.
정답을 찾은 뒤 모든 보기의 표현을 표시하고, 다른 보기도 계속 눌러 들을 수 있습니다. 추가 듣기는 오답·추가 점수로 기록하지 않습니다. 다음 놀이를 눌러야 넘어갑니다.

## 수학·개인정보
기본값 초등 1학년 단계: 수 비교·순서 100까지, 계산 20 이하, 11유형. 기초·첫걸음으로 낮출 수 있습니다. 전체 교과 과정을 대체하지 않습니다.
영어 수준·기기 음성·도감·기존 기록은 유지합니다. 유료 음성 서비스 연결 없음, 마이크·서버 기록 없음. 기록은 이 브라우저에만 저장됩니다.

## 행동 GIF
걷기·뛰기·잠자기를 기존 캐릭터 그림을 활용한 움직이는 GIF로 표시합니다. 초롱·반짝·퐁퐁 모두 지원합니다. 화살표 표시는 제거했습니다.
GIF는 HTML에 내장되어 별도 외부 이미지 서버나 추가 음성 서비스가 필요하지 않습니다. 한 번 캐시된 페이지에서는 오프라인에서도 표시됩니다.
iPad의 동작 줄이기를 사용하는 환경에서는 정지 그림으로 표시됩니다. 영어 보기를 눌러 표현과 뜻을 들을 수 있습니다.
