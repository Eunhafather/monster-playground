# 몬스터 친구 탐험대

v0.4 · iPad Safari용 영어·수학 놀이.

## 수학
기본값은 초등 1학년 단계입니다. 영어 난이도는 그대로 유지합니다.
수는 0~100 범위의 비교·순서, 계산은 20 이하입니다.
11유형: 끌어서 더하기·빼기, 목표 수 채우기, 두 자리 수 비교, 수의 순서·규칙, 모양 규칙, 빈칸 식, 이야기 계산, 십과 일, 정각·몇 시 반, 세 수 비교. 전체 교과 과정을 대체하지 않습니다.
보호자에서 기초(5 이하)·첫걸음(3 이하)으로 낮추거나 특정 유형만 연습할 수 있습니다.
한 놀이 4문제, 최근 문제 반복 완화, 도감과 기존 기록 유지.

## 음성·개인정보
영어 뒤 한국어 번역 재생. 기기 음성 읽기 기능을 사용합니다. 유료 음성 서비스는 연결하지 않았습니다. 마이크·계정·서버 기록 없음. 도감·설정은 이 브라우저에만 저장됩니다.
